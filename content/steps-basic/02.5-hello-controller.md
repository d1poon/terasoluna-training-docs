# Step 02.5 — はじめての Controller + JSP (Hello)

## このステップのゴール

**Step 03-05 で Domain / Repository / Service を組み立てる**前に、
「1 リクエストが Controller → JSP → HTML と往復する」体験を挟む**オプションのステップ**。

- `HelloController` を `demo-web/app/hello/` に配置
- `hello.jsp` を `demo-web/webapp/WEB-INF/views/hello/` に配置
- http://localhost:8080/demo-web/hello にアクセスすると自作 JSP が返る

> 💡 このステップは飛ばしても Step 03 に進めます。
> ただし、次に画面が出るのは Step 06 (ユーザ一覧画面) まで進めた後になるので、途中で不安になったらここで小さな成功体験を挟むと良いです。

Step 02 で Spring Security を無効化済みなので、**Controller と JSP を作るだけで素直に動きます**。Security 版のように「permitAll を設定する」「一時的に Security を無効化する」といった迂回策は一切不要です。

## 事前準備

- [Step 02](/steps-basic/02-empty-boot) 完了 (Tomcat 起動確認 + Spring Security 無効化)

```java
package com.example.demo.app.hello;

import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;

@Controller
public class HelloController {

    @GetMapping("/hello")
    public String hello(Model model) {
        model.addAttribute("message", "はじめての画面です");
        return "hello/hello";                                                  // ①
    }
}
```

- **① `return "hello/hello"`** — `spring-mvc.xml` の ViewResolver 設定 (`<mvc:view-resolvers>` / `<mvc:jsp>`) で `/WEB-INF/views/hello/hello.jsp` に解決される

```jsp
<%@ page contentType="text/html; charset=UTF-8" %>
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8" />
    <title>Hello — demo</title>
</head>
<body>
    <h1><c:out value="${message}" /></h1>
    <p>Controller から渡された文字がここに出ています。</p>
</body>
</html>
```

> `<c:out>` を使うのに `taglib` 宣言をしていない理由: `c` prefix は共通 `include.jsp` が全 JSP に自動前置するため既に使える状態にある。

## 動作確認

Tomcat 起動 → http://localhost:8080/demo-web/hello に直接アクセス → 「はじめての画面です」表示。**認証を求められることはない** (Step 02 で Spring Security の filter 自体を外しているため、ログイン画面へのリダイレクトも permitAll 設定もそもそも関係ない)。

## 何が起きたか (30 秒で)

1. ブラウザが `GET /hello` を送る
2. DispatcherServlet が `@GetMapping("/hello")` を持つメソッドを探して呼ぶ
3. `HelloController#hello` が Model に文字を詰めて `"hello/hello"` を返す
4. ViewResolver が `/WEB-INF/views/hello/hello.jsp` を描画
5. JSP の `${message}` がサーバ側で置換される
6. 完成した HTML がブラウザに返る

Security 版では手順 1 と 2 の間に「Spring Security Filter Chain が認証済みか確認する」ステップが挟まるが、このトラックではその工程が存在しない。このループが Step 06 以降の一覧・検索・詳細・変更の各画面で **同じ形で繰り返されます**。

## よくある詰まり

- **404 Not Found** — jsp の物理配置と `return "hello/hello"` のパスが不一致
- **`${message}` がそのまま表示される** — `<%@ page ... %>` の宣言忘れ、または EL が無効化されている
